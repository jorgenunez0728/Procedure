🔑 ¿Qué es la API Key y cómo la obtengo?

Esta herramienta usa la inteligencia artificial de Claude (Anthropic) para entrevistarte y redactar los procedimientos. Para funcionar, necesita una clave de acceso (API Key) a ese servicio.

📋 Pasos para obtenerla (5 minutos):

1. Ve a console.anthropic.com desde tu navegador

2. Crea una cuenta gratuita con tu email

3. En el menú izquierdo selecciona "API Keys"

4. Haz clic en "Create Key" y dale un nombre (ej. "KMX Lab")

5. Copia la clave que empieza con sk-ant-api03-...

⚠ Importante: La API key solo se muestra una vez al crearla. Guárdala en un lugar seguro antes de cerrar la ventana de Anthropic.

💰 ¿Cuánto cuesta?

Anthropic te da $5 USD de crédito gratuito al registrarte — suficiente para crear más de 600 procedimientos.

Generar un procedimiento completo cuesta aproximadamente $0.008 USD (menos de 1 centavo). No hay suscripción mensual obligatoria; solo pagas por lo que usas.

🔒 ¿Es seguro?

La API key se guarda solo en tu navegador (localStorage). No se envía a ningún servidor nuestro. La única comunicación externa es directamente entre tu navegador y los servidores de Anthropic para procesar el chat.
